Attention residuals: a learned weighting over layers

Standard residual connections add every layer's output with weight 1. Attention residuals replace this with a softmax over earlier layers. Block attention residuals keep the memory cost constant.

Naman Jaswani·13 September 2026·~7 min transformersresidualsarchitecture

In a standard transformer, the hidden state at layer L is the input embedding plus the output of every sublayer below it, added together with weight 1 each. A layer cannot give more weight to the earlier layers that matter to it and less to the ones that do not.

The Kimi team's paper on attention residuals (March 2026) replaces this fixed sum with a learned softmax over the earlier outputs. This post covers the two problems with the fixed sum, the fix, what the fix costs in memory, and the block version that keeps that cost constant.

The residual stream, written out

Take one pre-norm encoder layer. It reads the hidden state h_{l-1} coming from the layer below, runs multi-head attention on a normalised copy, adds the result back, runs the feed-forward network on a normalised copy of that, and adds again:

A= MultiHead(LN(h_{l-1}))attention branch mid= h_{l-1} + Afirst skip: add, weight 1 f= FFNN(LN(mid))feed-forward branch h_l= mid + fsecond skip: add, weight 1 h_l= [h_{l-1}] + A + fthe input passes through untouched

One pre-norm layer. Grey is the transforming path. Blue is the residual path: two skip connections, each added back with weight 1, so h_{l-1} reaches h_l without passing through any weights.

Look at the last line. Layer l does not change h_{l-1}. It passes it through and adds two vectors to it. Apply this across all layers and the final hidden state is the input embedding plus every sublayer output, each added with weight 1. Call the pair a layer adds v_l = A_l + f_l, and let v_0 = h_0 be the embedding:

h_L = h_0 + (A_1+f_1) + (A_2+f_2) + ... + (A_L+f_L) = h_0 + sum_{i=1}^{L} 1 * v_i

Two problems follow from that fixed weight of 1.

Pre-norm versus post-norm The equations above are the pre-norm arrangement, where LayerNorm sits on the branch and the residual path is a clean sum. The original 2017 encoder was post-norm, with the norm applied after each addition, which re-scales the stream at every layer and keeps the hidden state from growing in the way described next. Modern LLMs are almost all pre-norm, and the paper names the problem accordingly: PreNorm dilution.

Two things wrong with weight one

The hidden state grows with depth. Adding L vectors with weight 1 gives a norm that can be as large as the sum of the individual norms. Unless the sublayer outputs cancel each other, ||h_L|| grows roughly linearly with L, and nothing before the final norm limits it. This also dilutes each layer's contribution: layer 40's output is added to a sum that already has 80 terms in it, so it is a smaller fraction of the total than layer 2's output was. To have the same influence, a later layer has to produce a larger output.

There is no weighting, so there is no selection. Every earlier output enters with the same weight, whatever the token or its content. If three of the 96 sublayer outputs carry the signal a layer needs and the other 93 do not, the layer still receives all 96 at equal strength and has to separate them itself. The paper's talk gives the intuition: ask fifty people a question and average all fifty answers with weight 1/50, and the two people who actually know the answer are lost in the average.

Attention over depth

The fix is to attend over the earlier outputs. Instead of the fixed sum, layer l computes a softmax-weighted combination of every v_i below it, with the weights depending on the content of each v_i:

h_l = sum_{i=0}^{l-1} alpha_{i->l} v_i, alpha_{i->l} = softmax_i( w_l . RMSNorm(v_i) )

Here d is the model width: every v_i and every hidden state is a vector in R^d. The query is one learned vector w_l in R^d per layer, the same size as the v_i it is dotted with, so it adds d parameters per layer. The keys are the normalised earlier outputs. The values are the earlier outputs themselves. This is ordinary attention applied over depth instead of over the sequence, and it is computed per token: two tokens at the same layer can weight the earlier layers differently.

The softmax fixes both problems. Selection is what a softmax does. Bounded size takes one line: the weights are non-negative and sum to 1, so the result is a convex combination and its norm cannot exceed the largest input norm.

|| sum_i alpha_i v_i || <= sum_i alpha_i ||v_i|| <= max_i ||v_i|| (alpha_i >= 0, sum_i alpha_i = 1)

The softmax weights sum to 1, so the output is a convex combination and its norm is bounded by the largest input.

What the sources are My notes from the talk had the sum running over hidden states h_i. The paper attends over the sublayer outputs v_i, meaning what each layer added, not the running total. Under standard residuals h_{l-1} = sum_{i, so the two readings coincide only for the old scheme. With learned weights they are different, and the outputs are the right choice: the running totals overlap heavily with each other, and attending over them would make the softmax weights nearly uniform. The paper also applies the mechanism twice per layer, once before the attention sublayer and once before the FFN, which is why 48 layers give 96 sources. The figures below draw a layer as one unit to keep the picture readable.

What it costs to keep every layer alive

The cost is memory. Under standard residuals, layer l needs exactly one vector from below, h_{l-1}. The earlier outputs are already summed into it and can be discarded. Under attention residuals, layer l needs all of v_0, ..., v_{l-1} as separate vectors, because the weights depend on the current token and are not known until the layer runs.

sources read by layer l = l (v_0 .. v_{l-1}), total over depth = L(L+1)/2

Memory per token grows from d floats (one vector) to Ld floats (L vectors) at the top layer. The extra compute is small: each dot product is d multiplies, which is negligible next to what a layer already does. The memory is the cost. When a model is split across devices with pipeline parallelism, every device has to pass all L vectors to the next one instead of the single vector h_{l-1}. This O(Ld) cost is what block attention residuals remove.

Block attention residuals

The block version keeps the learned weighting between groups of layers and drops it within a group. Split the L layers into N consecutive blocks. Inside a block, use the ordinary residual: add the outputs with weight 1 into a running partial sum p_l. When a block is complete, its partial sum becomes one fixed summary vector b_n. A layer then attends over the finished block summaries plus its own block's partial sum:

b_n= sum over block n of v_isummary of a finished block p_l= sum of the current block so farpartial sum of the open block h_l= sum_n alpha_{n->l} b_n + alpha_{p->l} p_lsoftmax over the N_l summaries and p_l

Block attention residuals, six layers in three blocks. Blue additions inside a block are the ordinary residual sum with weight 1. Each finished block freezes to a green summary; the open block keeps a running partial sum. Layer 6 attends (violet) over the two summaries and the partial, so three vectors are alive instead of six.

Here N_l is the number of blocks completed below layer l. A layer in the last block reads N-1 summaries plus its partial sum, so it keeps at most N vectors regardless of depth, and only that many cross a pipeline boundary. The paper uses N = 8 and recovers most of the gain of the full scheme. Figure 2 shows the count against depth.

What is lost is the ability to weight layers inside the same block differently. If layers 17 and 18 share a block, layer 20 sees only their sum. The paper's ablations show that most of the gain comes from choosing between blocks, and little from choosing between layers within a block.

The takeaway

The residual connection is a weighted sum with all weights fixed at 1. Both of its problems, growth with depth and no selection, come from that fixed weight. Replacing it with a per-layer softmax fixes both: the softmax selects, and a convex combination is bounded by its largest term. The cost is memory: one state becomes L states, which matters under pipeline parallelism. The block version caps this at N states by giving up per-layer weighting inside a block. The paper finds eight blocks are enough.
